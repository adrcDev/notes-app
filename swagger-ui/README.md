This folder contains a React + React Router + Webpack project. It contains a single web page that provides documentation for the Notes website's REST API. It uses [`swagger-ui-react`](https://www.npmjs.com/package/swagger-ui-react) package's `SwaggerUI` React component to parse and render UI for /swagger-ui/src/static/yaml/notes-api.yaml file which contains documentation for the Notes website's REST API and is written in yaml using OpenAPI 3.0.0 specification. It has been deployed using [Render](https://render.com/) platform's static site deployment service and webpage is available at https://swagger-ui-rest-api-documentation.onrender.com.
